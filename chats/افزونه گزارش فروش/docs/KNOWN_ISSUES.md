# Known Issues / Watch List

این فایل بیشتر «مواردی که در توسعه بعدی باید مراقبشان بود» است؛ همه موارد الزاماً باگ فعال نیستند.

- اختلاف بازه تاریخ با WooCommerce می‌تواند در صورت حذف تنظیم ساعت شروع/پایان دوباره ایجاد شود.
- HPOS باید در هر تغییر Query سفارش تست شود.
- Transaction ID بین درگاه‌ها متای یکسانی ندارد؛ fallbackها نباید حذف شوند.
- CSV فارسی بدون BOM ممکن است در Excel با Encoding اشتباه باز شود.
- تبدیل مقدار مالی به رشته‌ای همراه با «تومان/ریال» باعث می‌شود Excel آن را عدد تشخیص ندهد.
- گزارش محصولات روی فروشگاه‌های بزرگ می‌تواند سنگین باشد؛ Batch processing و Cache فعلی باید حفظ/بهینه شود.
- در نسخه 1.1.0 هم `class-mmwsr-admin.php` و هم `class-mmwsr-export.php` منطق Export دارند؛ هنگام Refactor باید از ایجاد دو رفتار ناسازگار جلوگیری شود.
