# Decisions

1. نسخه مرجع توسعه فعلی `1.1.0` است.
2. Artifact مرجع همیشه ZIP واقعی داخل `release/` است.
3. تاریخ‌های UI شمسی باقی می‌مانند؛ Query داخلی باید با WooCommerce/HPOS سازگار باشد.
4. خروجی مالی باید عدد واقعی باشد و واحد پول به مقدار Cell چسبانده نشود.
5. مالیات و تخفیف سفارش جزو اطلاعات خروجی هستند.
6. نام محصولات سفارش باید در گزارش سفارش‌ها قابل مشاهده/خروجی باشد.
7. گزارش تعدادی محصولات صفحه مستقل خودش را حفظ می‌کند.
8. گزارش محصولات باید حداقل تعداد فروخته‌شده و مبلغ کل را نگه دارد.
9. برای حجم زیاد سفارش، پردازش Batch و Cacheهای کنترل‌شده حفظ شوند؛ نباید با Loop ساده و سنگین جایگزین شوند.
10. سازگاری HPOS نباید در تغییرات بعدی شکسته شود.
11. هنگام توسعه نسخه جدید، ابتدا ZIP فعلی باز و سورس واقعی بررسی شود؛ از بازسازی حدسی کد خودداری شود.
